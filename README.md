# Portfolio 👨‍💻

[![Igor Augusto's portfolio preview](docs/portfolio-preview.jpg)](https://igoraugusto.dev)

---

My personal portfolio, showcasing my experience, skills and projects in web and mobile development, backend integrations and AI agent solutions.

Built with **Next.js**, **React**, **TypeScript** and **Styled Components** to practice modern frontend development and share the work I have contributed to.

Explore the live portfolio at [igoraugusto.dev](https://igoraugusto.dev).

- Responsive layout with a dark theme and an animated starfield background.
- Content available in English and Portuguese.
- Project details with image galleries, technologies, challenges and learnings.
- Umami analytics for page views and LinkedIn/GitHub link clicks.
- Deployed with Vercel, with automatic deployments from the `master` branch.

Thanks for stopping by!
